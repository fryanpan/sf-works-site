What this list does not see

One row is not one project. btxj-k9uh holds 7,541 rows and 383 distinct projects — a project appears once per street segment. Every count on this page is projects.

Coverage is unmeasured. btxj-k9uh is the coordination list: work agencies filed with the Public Works coordinate application. What fraction of actual city street work reaches it is not published and this script cannot tell you. It is a floor, not a census.

0 rows carry no project id and are dropped. 20 projects carry no start date and sort to the bottom rather than the top.

The planned network is traced, not published. SFMTA published the North Star network only as a map inside the 2025 plan. That map is a vector PDF, so its lines are real geometry, and scripts/north-star-map-trace.py snaps them back onto DataSF street centerlines. A block near the edge of a drawn corridor is a judgement the trace made, not something SFMTA stated.

“The record does not say” is a silent field, not a No. The scope column reads three published fields — project name, description and owning agency. The description reads “NONE”, “N/A” or a ticket number on most rows, so the name carries nearly all of it. A project can be planning a protected lane and say nothing about it here.

High injury is still SFMTA’s 2022 layer, kept because the high-injury network is a separate product from the bike plan. Only 4,649 of the 7,744 segments under these projects (60%) appear in that layer at all, so a zero there means no record rather than no risk. The 2022 bike-priority columns that used to lead this page are gone: they pre-dated the 2025 plan and are superseded by it.

938 project rows list several segments in one field — cnn arrives as "['23348000', '23347000', ...]". They are unpacked. An earlier version of this script read that field as a single key, so those segments matched nothing and every priority and bikeway count on those rows was wrong.

The flag is the plan, not the pavement. A missing bike lane is not by itself a finding — most streets have none. What makes a row worth a letter is that the city’s own adopted plan says this street should carry biking and work is about to happen on it.

The moratorium column is a lock still in force on 2026-11-11 (2,507 segments), joined by cnn. A project overlapping one is either waiting for the lock to lift or holds a waiver from the Public Works Director — a decision with no public step.

Dates move. Public Works states that project planning runs on annual funding projections that “are very dynamic and can change at any time.” Nothing here is a commitment by the city.
